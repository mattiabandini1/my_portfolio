## 🚀 About The Project

I decided to build this portfolio using **Vanilla Web Technologies** (pure HTML, CSS, and JavaScript) instead of relying on heavy frameworks.

**Why?**
As an Engineering student, I believe in mastering the fundamentals. By avoiding dependencies, I achieved:
* ⚡ **Lightning-fast performance** (No heavy bundle loading).
* 🛠️ **Total control** over the DOM and styling.
* 📱 **Cross-browser compatibility** without build steps.

---

## 🛠️ Tech Stack

* **Structure:** Semantic HTML5
* **Styling:** CSS3 (Flexbox & Grid, Custom Variables for Dark Mode)
* **Logic:** Vanilla JavaScript (ES6+)
* **Deployment:** Vercel

---

## ✨ Key Features

* **Responsive Design:** Mobile-first approach, looks great on any device.
* **Dark/Light Mode:** System-preference aware theme switching.
* **Project Showcase:** Dynamic grid to display my work (FileInspector, SnapStudy).
* **Clean Code:** Organized directory structure and commented code for maintainability.

## 💻 How to Run Locally

Since this project uses no build tools or bundlers, running it is extremely simple.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mattiabandini1/my_portfolio.git
   ```

2. **Navigate to the folder:**
   ```bash
   cd my_portfolio
   ```

3. **Launch:** Simply open the `index.html` file in your browser.
   * Recommendation: For the best experience, use the "Live Server" extension in VS Code or Python's built-in server:
   ```bash
   # If you are on Fedora/Linux and have Python installed:
   python3 -m http.server
   ```
